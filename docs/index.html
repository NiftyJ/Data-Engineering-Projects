The warehouse, as a clickable star schema

The Adventure Works build reshapes Microsoft's OLTP database into a Kimball-style star schema, modelled in SSAS and reported in Power BI. Every relationship below exists as a real foreign key in AdventureWorksDW_Custom, rebuilt and orphan-validated by script. Click a fact table to see its grain and conformed dimensions, or click a dimension to see which facts reference it.

DimDate is role-playing — order, due, ship and work-order start dates all resolve to the same YYYYMMDD integer key. Full DDL, FK rebuild and validation scripts live in the repository.

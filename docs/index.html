The Adventure Works build reshapes Microsoft's OLTP sample database into a Kimball-style star schema in SQL Server, models it as an SSAS tabular project, and reports on it in Power BI. Evaluation design — the diagonal is in-distribution, everything off it is the cross-dataset test the study is actually about.

The literature says attention modules improve plant-disease detection. This study asks the harder question: do those gains survive a change of dataset, or do they only exist in-distribution? Four modules — SE, ECA, CBAM and Coordinate Attention — are grafted onto YOLOv8 at a single fixed insertion point, so the module itself is the only variable.

Each of the five variants trains on four harmonized datasets (PlantDoc, FieldPlant, DIAMOS, PlantSeg — masks converted to boxes, classes mapped to a shared scheme) across three seeds, then every trained model is evaluated on every dataset it never saw. Generalization gaps are tested with Wilcoxon signed-rank plus Benjamini–Hochberg correction, with Spearman correlation checking whether in-distribution rank predicts transfer rank at all. An earlier ResNet-50 classifier marks where this line of work began.

A hierarchy that trades

Deep RL · time series

NiftyBot Quant-Project Hierarchical-RL-

One network cannot be both patient and precise, so the system splits the job. A multi-head convolutional Strategist reads daily and 4-hour structure and commits to a bias — bullish, bearish, or stand aside. A PPO agent with LSTM memory, the Tactician, hunts entries on 15-minute charts and is architecturally forbidden from trading against that bias. The Strategist trains supervised on historical trend labels, then freezes while the Tactician learns by reinforcement around it.

The private Quant-Project pushes the idea further: instead of optimizing win rate, the objective is asymmetric payoff capture — accepting roughly 25% win rates in exchange for 10–100R winners — with GNN and vision modules feeding the state and MetaTrader 5 / Interactive Brokers handling execution. Hierarchical-RL- is the clean-room PyTorch core: a custom environment plus gated-residual-network layers of the kind used in modern time-series transformers.
